# 兼容性说明

本页整理当前开发代码中的适配范围。**已有实现、自动化测试通过和游戏内兼容验收是不同的状态**；
下面的范围不构成对所有模组版本或整合包组合的兼容保证。已发布版本以对应[发布说明](releases/)为准。

## 基础范围

当前目标为 Minecraft 1.21.1 / NeoForge，最低依赖版本由[构建配置](../gradle.properties)确定。
Fabric、Forge 和 Meteor 模块尚未创建。

原版采集实现包含玩家背包、末影箱、单/双箱、陷阱箱、木桶、潜影盒，以及熔炉、高炉、烟熏炉、
漏斗、酿造台、发射器、投掷器和合成器等持久存储菜单。临时或虚拟菜单不写入长期索引。
基础采集与持久化已有[真实客户端验收记录](validation/m2-m4-neoforge-alpha.md)，记录对应其注明的
日期和环境，不代表后续所有组合均已重新验收。

## 模组适配范围

| 对象 | 当前实现与采集条件 | 限制与验证状态 |
| --- | --- | --- |
| 标准组件物品容器 | 读取任意物品已同步的 `minecraft:container` 组件，保留槽号、variant 与递归路径 | 有端到端映射回归；不从 custom data 猜测库存，不推测组件没有记录的尾部空槽容量；具体模组交互仍需验收 |
| Sophisticated Backpacks 及 `tfcsbu` 背包 | 读取实际背包类型与已有客户端缓存；可位于玩家栏、受支持装备槽或容器内，递归计入总览与内容预览；需原模组先同步 | 有大数量、确认清空及暂不可读保留回归；同槽同身份才保留旧内容。升级图标仅展示，不计数；整合包交互仍待复测，不主动请求数据 |
| Curios 装备槽 | 首次观察玩家时初始化可选 API，读取实际装备槽并合入玩家库存；临时失败后重试。背饰内受支持容器沿相同递归链处理 | 核对 9.5.1+1.21.1 的 API 签名；当前实例索引只读回放含饰品背包，尚未复现完整漏统计触发过程；不等于全版本或游戏内验收 |
| TFC 大缸、木桶等存储菜单 | 按实际存储接口与菜单所属容器识别，过滤玩家栏和临时槽位 | 已核对 TFC 4.2.9 的相关结构并测试；其他菜单不按界面外观猜测兼容 |
| TFC 工具架与放置物品 | 瞄准或交互后读取明确类型的储物方块实体 | 排除自然地表散落物和掉落物实体；有回归测试，游戏内交互仍待复测 |
| Functional Storage 物品抽屉 | 读取普通及框架 1/2/4 槽物品抽屉，瞄准或交互后记录已同步数量 | 按 Functional Storage 1.5.4 / Titanium 4.0.45 核对并测试；未接入控制器网络、末影共享和压缩换算抽屉 |
| Functional Storage 流体抽屉 | 读取普通及框架抽屉的 1/2/4 个真实储罐、容量与体积 | 有回归测试，整合包交互仍待复测；排除锁定样板、创造无限视图和控制器代理 |
| 已同步的物品/方块储罐 | 读取 TFC 大桶、瓶、叠放桶、精妙背包储罐升级及嵌套物品内可用的流体数据 | 内容取决于原模组客户端同步；相关适配仍需游戏内复测 |
| 沉浸工程木制储物箱 | 读取实际 backing container，排除玩家栏和无关槽位 | 已核对 12.4.2 的结构并测试；整合包交互仍待复测 |
| 沉浸工程焦炉流体 | 通过可选 Jade 桥读取已接收并校验的目标数据，归并到主块 | 依赖 Jade 提供可用数据，读取失败保留上次记录；仍需游戏内复测 |
| 存储终端 | 提供按原容器身份合并可见槽位、部分观察和确认网络分组的扩展接口 | 只有接口与模拟终端测试；尚未内置 AE2、RS 等具体终端适配 |

瞄准采集只轮询有限数量的已观察目标，不扫描区块。对不能确认归属的网络汇总、无限库存或代理
视图，不将其当作额外的有限库存累计。

## 显示与验证边界

原版与 TFC 大箱子的双块几何、非矩形菜单布局已有显示实现与相关测试；旧记录可能需要重新
打开容器才能补全布局或朝向。完整整合包中的视觉与交互仍需复测。

玩家库存页支持已注册的装备来源及 Curios 实际槽位；不把任意模组的装饰界面推断为真实库存。
Shift 预览展示已记录数量、可用的槽位标签和升级图标；不推测 TFC 重量、大小或背包堆叠倍率。
中英文 GUI 5 倍的原生渲染和点击夹具通过，具体版本、索引回放与限制见
[2026-10-30 验证记录](validation/player-inventory-summary-2026-10-30.md)。

当前界面包含物品/液体查询、容器地图和会话获取计划；实际可通行路径、自动取物或自动搬运
不属于当前安装包能力。

另有[可选只读导航 Mod](navigation.md)，不内置于库存安装包。已有有限步行模型和独立/联装启动探针，
真实世界路线与特殊模组运动仍待验收；不能据此扩大库存采集或任意整合包的兼容范围。

接口及读取细节见[库存适配接口](inventory-adapters.md)。各次实现的版本依据、测试和待验收项见
[开发状态](development-status.md)与[验收记录](validation/)。新增兼容说明时，应同时记录目标模组版本、
采集前提、已执行的验证和仍未覆盖的范围。
