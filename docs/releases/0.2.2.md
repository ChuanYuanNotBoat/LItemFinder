# LItem Finder 0.2.2

发布日期：2026-10-27。Minecraft 1.21.1 / NeoForge 21.1.248+ / Java 21，仅客户端。

- 补充 Functional Storage 普通与框架流体抽屉：支持 1/2/4 个真实储罐，瞄准即可记录已经同步到客户端的液体体积和容量。
- 直接接入已有液体列表和地图，支持容量升级及取放、清空后的观测更新；流体抽屉不会生成物品库存副本。
- 排除锁定样板、升级槽、控制器代理与创造无限流体。创造视图在读取内容前跳过，避免原模组 getter 对活跃流体栈的数量修改。
- 读取不可用时保留旧记录，明确读到空罐时更新为零；通过通用方块流体适配接口接入，Core 的汇总、持久化字段和地图投影共用现有实现。

验证：对照本地 Functional Storage 1.5.4 / Titanium 4.0.45 的真实 JAR 核对同步与读取接口；自动回归包含普通/框架 1/2/4 罐、1.2 B / 32 B 显示值、容量变化、锁定空罐、清空、创造视图、代理排除、读取失败，以及进入 Core 汇总和世界地图的链路。实际整合包内的交互效果仍需更新后验收。

安装 JAR、完整构建源码、安装发布包和 SHA256SUMS 随版本提供。实例中的 JAR 可在正常退出游戏后替换，不要求清空旧索引。
