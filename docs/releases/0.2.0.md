# LItem Finder 0.2.0

发布日期：2026-10-26。Minecraft 1.21.1 / NeoForge 21.1.248+ / Java 21，仅客户端。

- 读取玩家物品栏、真实 Curios 饰品栏及已同步的精妙背包嵌套内容，兼容 tfcsbu 背包与大堆叠。
- 保存菜单实际槽位布局；支持 TFC 工具架、放置物品和锭堆、Functional Storage 普通/框架抽屉、沉浸工程木制储物箱。
- 加入独立液体页，使用原液体纹理、颜色、容量及 mB/B/kB/MB 单位，列表和页头更紧凑。
- 液体条目可展开来源并定位到容器地图，复用路线接口；瓶、桶、背包内的液体保留实际物品路径，随身来源不会生成虚假世界坐标。
- 物品内液体随内容变化更新，叠放桶按数量累计；精妙背包储罐升级装入或拆下后均可识别，拆下时容量未知则仅显示体积。
- 准星瞄准采集已同步储罐；沉浸工程焦炉仅读取 Jade 已接收且校验通过的当前目标数据，并归并到多方块主块。失败或数据不可用时保留旧记录。
- 存储终端接口按实际容器身份分组与合并，仅刷新可见槽位；未观察页面保留历史数据。
- 移除地图水域和等高线叠加；改善地图渲染、双箱形状及朝向。
- 提供可安装 JAR、完整构建源码、安装说明及 SHA-256 校验文件，运行 ./gradlew release 可重复打包。

适用范围：兼容代码已对照本地整合包版本结构检查，并有自动化回归测试。终端接口使用模拟终端测试，尚未附带 AE2/RS 专用适配；本地实例没有这些模组。未安装导航提供者时路线仍为停靠点示意连接线，不包含地形寻路。客户端未收到的物品或流体数据不会主动向服务端请求。实际游戏交互仍需在重启更新后的实例中验收。
