# LItem Finder 0.2.1

发布日期：2026-10-26。Minecraft 1.21.1 / NeoForge 21.1.248+ / Java 21，仅客户端。

- 物品与液体改为同一页面内切换下半部分列表，共用标题、搜索、地图、设置和容器上下文。两种模式分别保留搜索内容，物品获取草稿不受切换影响。
- 液体沿用物品列表的图标、名称、右侧数量、行高、颜色和展开区样式；行内展示容量、精确 mB、容量条和观测时间。
- 移除独立液体页面和来源页面，地图直接提供液体模式，显示图标、体积与容器详情，按选中液体高亮储存位置并复用路线接口。
- 将通用能力下沉 Core：观测范围与分页合并、过期更新拒绝、液体持久化字段、不可用数据保留、容器/液体投影、存储分组与位置解析。具体模组读取和原生组件解码保留在适配层。
- 增加 Core 导入边界检查，独立验证不依赖游戏的规则；新增旧版 SQLite 字段兼容、同页切换与草稿保留、液体地图目标随清空更新的回归测试。

验证：177 项自动化检查通过，覆盖全部模块与安装 JAR 的依赖/许可证验证。液体地图沿用已有导航能力，未安装导航提供者时显示停靠点示意线；随身液体不生成虚假世界坐标。保留版本 1 快照 metadata 与 SQLite schema，更新不要求清空旧索引。实际整合包内的界面效果仍需重启后验收。

安装包、完整构建源码和 SHA256SUMS 随本版本一并提供。正常退出游戏后替换旧版 JAR，保持 mods 内只有一个 LItem Finder 版本。
