# 使用说明

本页描述当前开发代码的使用方式。已发布版本的功能以对应的[发布说明](releases/)为准；
当前阶段为 beta，具体适配与验证范围见[兼容性说明](compatibility.md)。

## 记录库存

打开受支持的持久容器后，模组记录客户端已经同步的库存。部分方块可在瞄准或交互后读取；
背包等嵌套容器需要所属模组先向客户端同步内容。模组不主动请求背包或远处容器的数据。

玩家背包会观察本地变化。已观察的方块只在客户端可读取时更新，不遍历世界区块。
工作台、铁砧、村民交易和创造模式物品选择等临时或虚拟菜单不写入长期索引。
记录是上次成功观察的快照；读取不可用时保留旧记录，不能将显示的数量理解为远程实时库存。

## 界面

按 `O`（可在按键设置中修改）或输入 `/litemfinder gui` 打开界面。

- 库存总览提供搜索、物品/液体切换和数量查看。
- 容器内容页显示记录的槽位及嵌套内容；有布局数据时按实际槽位排布，旧记录回退为网格。
- 物品获取计划按精确物品变体与已记录槽位分配来源，并报告缺货。计划仅保存在本次游戏会话中，
  不执行自动取物。
- 容器地图显示已记录容器的位置、内容与停靠点。随身容器或液体没有可用世界坐标时，
  不生成世界停靠点。

在 2D 或局部 3D 地图中点击本地玩家指针，可打开玩家物品栏；侧栏的“玩家物品栏”也提供相同入口。
内容页包含已采集的物品栏、盔甲、副手和受支持饰品槽，“装备/饰品”按钮可定位饰品区域。
这里查看的是本地玩家的记录，不是其他玩家未同步的库存。

悬停在背包等容器物品上，按住 **Shift** 查看已记录内容的汇总图标和精确数量；已同步的背包升级
单独展示，不计入物品统计。**点击绿色槽位**进入原槽位格子页，保留空格和槽号，可逐层打开、返回上层。
汇总和库存总览均包含已记录的嵌套内容；尚未同步时会提示先在原模组中打开或 Shift 悬停。
如果同槽同身份背包的内容暂时不可读，会显示上次成功观测的内容并提示；确认清空或更换背包后不会沿用旧内容。

地图当前内置连接线按停靠点位置绘制，不包含地形通行验证。库存安装包不内置导航服务；
可选独立导航模块已有首批实现，成品启动与联装服务发现已验证，真实世界路线仍待验收，
命令及限制见[可选导航](navigation.md)。
已移除地形采样、水域和等高线显示。

路线变化时，起点附近的小幅变化平滑更新，停靠顺序或路线形状变化淡出后再显示新线。可选导航
重算期间若仍显示旧路径，会提示正在更新；这些显示过渡不会将停靠示意线变成可通行路径。
地图下方摘要给出目的地、方式、完整度、估时、缺口原因及下一步；内容较多时可以滚动。
“详情”展开分段坐标和可用证据，“重新计算”重新请求。部分路线的估时仅覆盖已验证部分，
当前步行估时按基础速度计算，尚未按玩家实际速度校准。

## 液体

液体与物品使用相同页面的搜索和位置查询入口，按储罐独立记录，不计入物品数量。
点击液体行可展开容量等详情，悬停查看精确体积与观测时间。液体查询不加入物品获取数量草稿。

体积以 `mB` 保存，界面可按桶数缩写：

| 显示 | 对应体积 |
| --- | --- |
| 1 B | 1,000 mB |
| 1 kB | 1,000 B |
| 1 MB | 1,000,000 B |
| 1 GB | 1,000,000,000 B |

可读取的储罐取决于原模组同步内容，见[兼容性说明](compatibility.md)。

## 客户端命令

```text
/litemfinder stats
/litemfinder compat
/litemfinder gui
/litemfinder search <文本>
/litemfinder exact <namespace:item>
/litemfinder clear
/litemfinder clear confirm
```

`stats` 查看索引状态，`compat` 查看可选清单插件的载入、跳过与失败情况（不含内置适配器计数），
`search` 按文本搜索，`exact` 按物品注册 ID 查询。
`clear` 只显示确认提示；完整输入 `clear confirm` 才会删除当前世界或服务器的索引。

## 数据与卸载

索引按世界或服务器隔离，存放于：

```text
<游戏目录>/config/litemfinder/index/<scope-hash>.db
```

数据库文件名、容器 ID 和 metadata 不保存原始服务器地址或本地存档路径。
自动判定容器被销毁时，会先将完整快照保存在 `config/litemfinder/index/removed/<scope-hash>.db`，
写入失败则取消删除。该文件保存每个根容器的最新删除前快照，不自动加入当前库存统计。
`clear confirm` 同时清除当前 scope 的这些自动恢复副本。

手工恢复的历史记录会显示“历史恢复 · 内容不完整”；问号表示没有确认该槽位，容量未知也会明确提示。
只有位置的记录不计入物品数量。重新打开实际容器后，新的完整观测会替换记录并清除恢复提示。

卸载时先正常退出游戏，再删除 `mods` 中的 LItemFinder JAR。
若同时移除本地索引，可删除 `config/litemfinder` 目录；删除索引不可撤销。
